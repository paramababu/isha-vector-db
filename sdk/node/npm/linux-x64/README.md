# @isais-logic/isha-vector-db-node-linux-x64

The native addon for `linux-x64`, built from `x86_64-unknown-linux-gnu`.

Not installed directly. `@isais-logic/isha-vector-db-node` declares every platform package as an
optional dependency with `os` and `cpu` constraints, so npm downloads only the one that
matches the machine doing the installing.
