vdb on IndexedDB

The IndexedDB fallback, for browsers where OPFS is unavailable — older Safari, and private browsing modes where the origin private filesystem is restricted. IndexedDB has no synchronous API at all, so the whole database is held in memory and written back in 64 KiB blocks; this page checks that the write-back actually persists.

Reload after the first run: the second run must find the database still there.
