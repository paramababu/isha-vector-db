vdb on OPFS

The Node tests cover the whole stack against a stand-in for OPFS. This page is the part only a browser can answer: whether real FileSystemSyncAccessHandle behaves the way the adapter assumes. Serve this directory over HTTP and open it — OPFS needs a secure context.

The work happens in a Worker, because createSyncAccessHandle() does not exist on the main thread. That is the supported way to run this SDK, so the worker doubles as the usage example.

Reload after the first run: the second run must find the database still there.
